# W3C WoT Thing Description 1.1 の JSON Schema

`td-json-schema-validation.json` は https://www.w3.org/2022/wot/td-schema/v1.1 (W3C 公開版, version 1.1-12-March-2025) をそのまま保存したもの。
wot_td.py が作る TD がこれに合うことを test/test_units.py と experiments/check_stage6.py で確かめる。
