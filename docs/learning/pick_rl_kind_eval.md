# Stretch 3 で床の小さい物を拾う — 計算で決めた拾い方と学習した補正の比較

学習した補正: `learning\rl_pick\per_kind` (learning/rl_pick、詳しくは [pick_rl.md](pick_rl.md))。

`learning/eval_pick.py` で作成 (種類ごとに 200 回、seed 0、timestep 0.005、制御の周期 0.020 s)。 考察と注意は [pick_notes.md](pick_notes.md)。

成功 = 物が元の高さから 5 cm 以上上がり、そのまま 2 秒落とさない。乱数で変えたもの: 物の位置 (腕の帯 横 0.12〜0.45 m・前後 ±0.15 m)、向き、摩擦 0.5〜1.2、台車の止まる位置 ±3 cm・±5°、ロボットに渡す位置の見積もり ±1 cm・向き ±10°。

物理の設定: **家の既定** = 今の家のシミュレーション (MuJoCo の既定: Euler・pyramidal・impratio 1・noslip なし)。**noslip 3** = それに `noslip_iterations=3` だけ足したもの (Microduck の歩き方は変わらないことを確かめた)。
