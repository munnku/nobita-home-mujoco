# レポートの下書き (MuJoCo 版)

提出物「説明資料_PAI最終課題_Munnku_Ken」(PDF) のもと。数字は 10/19 時点で、最終版で取り直す。

## 1. 課題と提案
- 課題：一人や高齢の家族が家で倒れても、だれも気づかない。家じゅうにカメラを付けても、死角や確認の手が足りない。
- 提案：家に付いている IoT 機器が「いつも見て」、二足歩行の小型ロボットが「近くで確かめて声をかけ」、
  LLM が「人の頼みを機器とロボットの操作に変える」。この 3 つで家族を見守る。
- 舞台：2 階建ての日本家屋。間取り図から MuJoCo で作った。

## 2. しくみ
- **全体の図**：PLAN.md の構成図。MQTT の上で 4 つのプロセスが動く。
- **規格**：手で作ったつなぎ方ではなく、既存の規格を使った。
  - MQTT（通信）
  - Homie 4.0（家電の記述と値）
  - VDA 5050 v2.0（ロボットへの指示。工場の無人搬送車の規格を家のロボットに使った）
  - W3C WoT TD 1.1（機器の説明書。30 台分を MQTT の記述から自動で作り、公式のスキーマで検証した）
- **家**：間取り図を半間のマス目で読み取った YAML から、MJCF を自動で作る。
  - 1 階・2 階、扉（開き戸・引き戸の関節）、窓、階段がある。
  - 床面積は記事の推定値と一致する。
- **ロボット**：Microduck（Pollen Robotics、高さ 25 cm の二足歩行）。
  - 歩き方は公開されている強化学習の方策（ONNX）をそのまま使う。サーボのモデル（BAM）も学習時と同じにした。
  - LiDAR を使わず、家の地図（間取りから作る）の上で A* と pure pursuit を使う。
  - 人を見るときは、家具に視界をふさがれない立ち位置を自分で選ぶ。
- **見守りカメラ**：YOLO の枠から、床の上の位置と姿勢（立っている / 横になっている）を推定する。

## 3. 学習
### 3.1 YOLO の追加学習（データを作って学習）
- **データ**：MuJoCo で人の置き場所・向き・姿勢・照明をランダムにし、見守りカメラとアヒルの頭のカメラで撮った。
  - 正解の枠は、セグメンテーションの描画から自動で付けた。
  - 7119 枚（立っている人 3076 人、横になった人 4471 人）。
- **学習**：YOLOv8s を 2 クラスで転移学習した。RTX 3060 で 30 エポック、約 50 分。テストの mAP50 は 0.986。
- **結果**：横になった人を見つけて姿勢も正しい割合は次のとおり（表は PLAN.md）。
  - 見守りカメラ：28% → 97%
  - アヒルの頭のカメラ：15% → 94%
- **場面での効果**：家具の陰の転倒（DK・応接室）は、学習前は見逃して知らせが出なかった。学習後はアヒルが確認して知らせた。

### 3.2 歩き方の強化学習
- 公開の方策は、この家のシミュレーションでは速度指令の 1/3 ほどしか進まなかった（0.4 m/s の指令で 0.14 m/s）。
- microduck_rl（mjlab / MuJoCo Warp、PPO）で、Velocity-Flat-Backlash を学習した。
  - 4096 環境・1500 回更新、RTX 3060 で約 2.5 時間。
- 結果：
  - 0.4 m/s の指令で 0.34 m/s 進むようになった（公開の方策の 2.4 倍）。
  - 転倒を知らせるまでの時間が 4〜5 割短くなった（DK 53.8 秒 → 29.6 秒、応接室 40.6 秒 → 23.6 秒、居間 15.6 秒 → 11.0 秒。実時間の 2 倍、3 回ずつ）。
  - 表と学習曲線は PLAN.md と docs/learning/rl_curve.png。
- 弱点：小さい指令では足踏みになり、旋回は公開の方策の半分ほどの速さ。

## 5. 限界と今後
- 人は置物（姿勢は立つ・横になるの 2 つ）。座る姿勢や動作は無い。
- 学習データは同じシミュレーションの同じ人で作ったので、実物の精度は分からない。服装・体型・照明を増やす、または実写を足す必要がある。
- アヒルの位置は正しい位置（シミュレーション）を使っている。実物では、UWB や見守りカメラでアヒルを見つけるなどの自己位置推定が要る。
- アヒルは階段を上れない。2 階は機器だけで見守る。
- 学習した歩き方は旋回が遅く、小さい指令では足踏みになる。学習の延長と、床の摩擦の乱数化が要る。
